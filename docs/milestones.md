# Milestones

## Milestone 0: Análisis y modelado del problema

Es el primer producto interno de AeroPLan. parte únicamente de la HU001, relacionada con el problema de poder volar en la zona de un encargo. A partir de esta historia se identificarán los conceptos principales del problema y se estrablecerá una forma común de nombrarlos y relacionarlos, de manera que quede claro qué representa cada elemento que posteriormente aparecerá en el código.

El resultado se reflejará en el código inicial del protect, todavía sin ninguna lógica de negocio, y en la documentación en docs, donde se justificará el análisis realizado. 
El milestone se considerará completado cuando sea posible seguir desde la HU001 hasta los conceptos indentificados y entender por que cada elemento forma parte del código. No debería de existir ningún elemento que no pueda justificarse a partir de la HU.

## Milestone 1: Lógica y pruebas

Es el segundo producto interno de AeroPlan y parte de lo que se entregue en el milestone anterior.

Se entrega la lógica que resuelve el problema planteado en la HU001, acompañada de pruebas automáticas, y de aquello que sea necesario para poder ejecutarlas desde el repositorio. En este punto todavía no hay interfaz gráfica, ya que el objetivo es validar el comportamiento del dominio

El milestone se considerará completado cuando las pruebas se ejecuten automáticamente y pasen.
